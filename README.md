## Описание выполненных заданий

В рамках лабораторной работы были реализованы 5 модулей, охватывающих различные аспекты разработки под iOS.

### 1. Управление фоном (Swift + UIKit)
Реализовано приложение с динамической сменой графического интерфейса.
* **Функционал:** Использование компонента `UISwitch` для переключения между двумя фоновыми состояниями.
* **Технические детали:** * Ресурсы оптимизированы и добавлены в `Assets.xcassets` (наборы `2x` для Retina-дисплеев).
  * Связь интерфейса с кодом реализована через `IBOutlet` (для `UILabel`) и `IBAction` (для обработки события `valueChanged`).
  * Логика: программное управление свойством `.image` у `UIImageView`.

### 2. Информационный гид (Objective-C)
Разработано многоязычное приложение для отображения данных о городах и заведениях.
* **Функционал:** Вывод информации о температуре, ресторанах и типах кухни.
* **Технические детали:**
  * Работа со словарями `NSDictionary` для структурированного хранения данных.
  * Реализована локализация (RU, EN, PL) через файлы `.strings` и макрос `NSLocalizedString`.
  * Добавлена визуальная логика: цвет текста температуры меняется программно (красный/синий) в зависимости от значения.

### 3. Калькулятор здоровья (Swift)
Инструмент для расчета физических показателей пользователя.
* **Функционал:** Расчет индекса массы тела (BMI) и суточной нормы калорий (BMR).
* **Технические детали:**
  * Использована формула Гарриса-Бенедикта.
  * Работа с пользовательским вводом через `UITextField` (с ограничением на цифровую клавиатуру).
  * Интеграция `UISegmentedControl` для выбора пола и уровня активности.

### 4. Игра «Color Matcher» (SwiftUI)
Интерактивное приложение, созданное с использованием декларативного подхода.
* **Функционал:** Игра на подбор цвета с помощью трех слайдеров (RGB).
* **Технические детали:**
  * Использование оберток состояния `@State` для реактивного обновления интерфейса.
  * Реализация механизма `Binding` для связи ползунков с текущими значениями цвета.
  * Работа с графическим контекстом SwiftUI для отображения целевого и текущего цветов.

### 5. Универсальный конвертер размеров (Swift + Auto Layout)
Справочное приложение для перевода размеров одежды и обуви между мировыми стандартами.
* **Функционал:** Конвертация размеров для рынков EU, US, UK и RU.
* **Технические детали:**
  * Интерфейс спроектирован с использованием `UIStackView` для автоматического распределения элементов.
  * Настройка ограничений (`Constraints`) для поддержки разных размеров экранов и ориентаций (Portrait/Landscape).
  * Реализована динамическая смена фона при переключении категорий товаров.
